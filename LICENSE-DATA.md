# Data licence

The code is MIT. Data derived from Meta's Seamless Interaction dataset
(manifest/*.jsonl: clip windows, labels, transcript excerpts, system prompts,
AV captions, human review decisions) is released under CC BY-NC 4.0, the
licence of the source dataset, with attribution to Meta AI. The NVIDIA
VideoFDB dataset is gated and non-redistributable; this repository contains
only a loader for it and never any of its media or annotations.

See also the dataset card at https://huggingface.co/datasets/OpenHRI/open-videofdb.
